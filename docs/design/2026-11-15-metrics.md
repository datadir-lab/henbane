# Metrics endpoint

## Goal

Make the value Henbane delivers *visible*. The honest story is that the tarpit
imposes real, measurable cost on crawlers (bytes served, pages fetched, bot-vs-
human ratio) while model-level poison impact is unobservable. An operator should
be able to see the measurable half: how many bots were classified, how many maze
pages they were made to fetch, which signals fired.

## Shape

A `ports.Sink` (`internal/adapters/metrics.Registry`) consumes every decision
Event (the same event stream the slog and fail2ban sinks already see) and
folds it into counters, rendered on demand in the Prometheus text exposition
format **by hand** (no client library; stdlib-only rule holds).

Counters:

- `henbane_requests_total{action,tier}`: decisions, by final action and tier
  (allow/challenge/tarpit/poison/block × pass/suspect/confirmed/blocked). The
  `allow` count vs the rest is the human-to-bot ratio; `tarpit` is maze pages
  served.
- `henbane_signals_total{signal}`: how often each detector fired.
- `henbane_signals_dropped_total`: appears only if the signal-label cardinality
  cap is ever hit.

## Why a separate listener

The counters are aggregate (no per-IP, per-path, or per-UA labels), but they are
still operational data that must not be exposed to the public, least of all to
the crawlers being counted. So metrics are served on their own listener
(`metrics.listen`), which the operator binds to a private interface. Config
rejects `metrics.listen == listen`. Empty `metrics.listen` disables it.

## Zero-trust / DoS

- **No high-cardinality labels.** Action/tier are small fixed enums (indexed
  array of atomic counters, out-of-range codes ignored, no OOB). Signal labels
  are developer-defined, but the distinct-label count is still hard-capped
  (`maxSignals`) with an overflow counter, so no future detector (or bug) can
  blow up memory through label cardinality.
- **Non-blocking.** Request/tier counts are atomic; the signal map takes only a
  brief lock. Concurrency is `-race` tested.
- **Label escaping.** Signal values are escaped per Prometheus rules so the
  exposition format stays valid regardless of the signal string.

## Scope / non-goals

- v1 counts classifier *decisions* from the existing event stream. Byte-level
  accounting ("GB streamed into the tarpit") would need proxy-level
  instrumentation and is a clean follow-up; `tarpit` page count is the v1 proxy
  for it.
- No histograms, no auth on the endpoint (operator firewalls the private
  listener). Off by default, like the PoW gate and the bomb.
